# FinTrace README assets — installation guide

This archive contains a replacement **root** `README.md` and its accompanying visual assets.

## Installation

1. Unzip the package.
2. Copy `README.md` to the root of `Vedanto28/fintrace`, replacing the existing root README only.
3. Copy the full `docs/assets/` directory into the repository, retaining filenames and relative paths.
4. Preview the root README in VS Code or GitHub.
5. Commit and push when satisfied.

All graphics were generated for this README in a black/orange Web3-inspired **aesthetic**. They do not imply blockchain/Web3 integration.

## Assets

- `fintrace-hero.gif`: animated 3D globe / hero (conceptual, not a production recording)
- `fintrace-hero.png`: static fallback
- `hero-preview.png`: small PNG preview
- `telemetry-stream.gif`: animated illustrative sample trace data replay
- `telemetry-preview.png`: static frame from the illustrative sample
- `architecture.svg`: architecture visualization
- `capabilities.svg`: product feature overview

The GIFs are self-contained and loop in GitHub. Do not move them without adjusting README paths.

## No code changes

This package does not change frontend, backend, Electron, dependencies, or deployment settings. It only adds documentation and graphics. The original repository remains unchanged until you upload files manually.
