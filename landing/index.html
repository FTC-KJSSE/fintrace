    How it works

    A browser cannot run a traceroute.
    So FinTrace isn't one.

    Traceroute needs a raw socket — a privilege the browser sandbox exists to withhold. So FinTrace ships as a native binary, spawns your own tracert, and reads the result line by line. The measurement is yours, taken on your connection.

    tracert -d Tracing

    Sample output. Timed-out hops are shown, not hidden — real routes have them. Every figure above is computed from the table, not asserted.

    A web page cannot

    • ✕Open a raw ICMP socket
    • ✕Set a packet's TTL
    • ✕Spawn a system process

    FinTrace does

    • ✓Spawns native tracert -d
    • ✓Geolocates hops offline
    • ✓Renders the route in 3D

    Three ways to run it

    Single
    One trace to one endpoint.
    Live
    The same route re-fires every 30 seconds.
    Compare
    Up to six endpoints at once, each in its own colour.
    What you can trace

    Nine curated targets. Or any host you like.

      Download

      Free, open source, one release.

      Two Windows x64 builds. Pick the installer for a normal setup, or the portable executable if you'd rather not install anything.

      On macOS or Linux? There is no prebuilt binary yet — clone the repo and run npm install && npm run electron:dev. The trace uses traceroute -n on those platforms.
